# fluxnet_project
*4th Year Masters Project investigating the effects of vapour pressure deficit (VPD) on gross primary productvitiy (GPP)*

This repository contains data cleaning, exploring and analysis code for my 4th year undergraduate research project.

## Research question
How does vapour pressure deficit (VPD) affect gross primary productivity (GPP) across global FLUXNET sites?
- Across climates
- Across plant functional groups
- The role of soil moisture
- Average VPD versus short term extreme VPD events and their legacy effects

## Data
- FLUXNET2015 / FluxDataKit derived data
- Raw data not stored in this repository
